# APES Electrical Tools
APES Electrical Tools es un software de diseño de instalaciones eléctricas industriales, que ayuda a crear documentación sobre listas de cargas, arquitectura eléctrica y dimensionamiento de baterías de condensadores. Tiene opciones para exportar a Excel (*.xlsx), AutoCAD (*.dxf y *.dwg) y vectorizado (*.svg).

## Política de IA
Se ha hecho uso de Inteligencia Artificial Generativa para el diseño de este programa. No obstante, ha sido supervisado por miembros de APES.
